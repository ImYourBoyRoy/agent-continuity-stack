# Update audit report

## Scope

- Repository or workspace:
- Evidence checked on:
- Audit tier:
- Ecosystems detected:
- Sources explicitly tracked:
- Checks skipped:
- Continuation queue:

## Priority summary

State the highest-priority security, compatibility, migration, maintenance, and
upstream-enhancement findings. Say `No finding` for an empty category.

## Findings

| Component | Current | Allowed | Available | Appropriate | Class | Confidence |
|---|---|---|---|---|---|---|

For each actionable row, add:

- evidence and source
- material changes
- compatibility constraints
- recommended action
- verification gate
- rollback requirement

## Proposed batches

Group tightly related changes. Keep security response, required compatibility,
routine maintenance, and major migrations separate.

## Limitations

List unavailable tools, private registries, missing pins, network failures,
ambiguous source relationships, and unverified compatibility. Never omit a
component silently because current evidence was unavailable.
