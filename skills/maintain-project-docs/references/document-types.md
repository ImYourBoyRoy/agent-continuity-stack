# Documentation ownership

| Information | Preferred home |
|---|---|
| Purpose, quick start, common usage | README |
| Contribution setup and checks | contributor guide |
| Stable architectural decision | ADR |
| Operational procedure and recovery | runbook |
| User-facing interface | generated or maintained API reference |
| Breaking transition | migration guide |
| Version-specific change | changelog or release notes |
| Active work state | issue, task, or temporary handoff |
| Repeated agent constraint | repository instruction |

Prefer links over copied content. Keep a fact in one authoritative location and
let summaries point to it.
